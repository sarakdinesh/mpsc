# गट-क सराव

MPSC गट-क सेवा संयुक्त पूर्व परीक्षा (24 जानेवारी 2027) साठी 62 दिवसांचा अभ्यास व सराव web app.

**App उघडा:** https://sarakdinesh.github.io/mpsc/

- दिवसानुसार आराखडा (नोकरी 12–9 नुसार)
- 79 धडे: सविस्तर नोट्स, छोट्या नोट्स, सापळे (चालू घडामोडींच्या धड्यांत स्रोतांच्या लिंक)
- 2,850+ प्रश्न (questions.js मध्ये; 2026, 2022, 2019, 2018 च्या पूर्वपरीक्षेतील प्रश्नांना वर्षाचा टॅग) + गणित/बुद्धिमत्तेचे अमर्याद प्रश्न
- चालू घडामोडी वेगळ्या `current-affairs.js` मध्ये: 9 धडे, 162 प्रश्न. प्रत्येक प्रश्नाला कायमचा id (उदा. `ca3-007`), पडताळणी स्थिती व शक्य तिथे स्रोताची लिंक. दर महिन्याला फक्त ही फाइल अद्ययावत करा.
- मॉक टेस्ट (100 प्रश्न, 60 मिनिटे, −0.25)
- प्रत्येक मॉकनंतर सर्वात कमजोर धड्यांतून 25 प्रश्नांचा ड्रिल
- प्रगती पानावर कट-ऑफ ट्रॅकर: मॉक गुण विरुद्ध मागील Open कट-ऑफ (अंदाजे, स्रोतासह; `index.html` मधील `CUTOFF` यादी)
- रोजची 3 न चुकवायची कामे (उजळणी, 1 चाचणी, 30 मि. चालू घडामोडी) आणि त्यांचा सलग दिवसांचा हिशेब

- एकदा उघडल्यावर इंटरनेटशिवायही चालते (Home screen वर install करा)

प्रगती फोनच्या ब्राउझरमध्ये जतन होते. "प्रगती" पानावरून बॅकअप फाइल घ्या व दुसऱ्या फोनवर तीच फाइल उघडून प्रगती परत मिळवा.
