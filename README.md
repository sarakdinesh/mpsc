# गट-क सराव

MPSC गट-क सेवा संयुक्त पूर्व परीक्षा (24 जानेवारी 2027) साठी 62 दिवसांचा अभ्यास व सराव web app.

**App उघडा:** https://sarakdinesh.github.io/mpsc/

- दिवसानुसार आराखडा (नोकरी 12–9 नुसार)
- 78 धडे: सविस्तर नोट्स, छोट्या नोट्स, सापळे (चालू घडामोडींच्या धड्यांत स्रोतांच्या लिंक)
- सुमारे 510 प्रश्न + गणित/बुद्धिमत्तेचे अमर्याद प्रश्न
- मॉक टेस्ट (100 प्रश्न, 60 मिनिटे, −0.25)

प्रगती फोनच्या ब्राउझरमध्येच जतन होते.
