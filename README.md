# गट-क सराव

MPSC गट-क सेवा संयुक्त पूर्व परीक्षा (24 जानेवारी 2027) साठी 62 दिवसांचा अभ्यास व सराव web app.

**App उघडा:** https://sarakdinesh.github.io/mpsc/

- दिवसानुसार आराखडा (नोकरी 12–9 नुसार)
- 78 धडे: सविस्तर नोट्स, छोट्या नोट्स, सापळे (चालू घडामोडींच्या धड्यांत स्रोतांच्या लिंक)
- 1,080+ प्रश्न (questions.js मध्ये; 2026, 2022, 2019, 2018 च्या पूर्वपरीक्षेतील प्रश्नांना वर्षाचा टॅग) + गणित/बुद्धिमत्तेचे अमर्याद प्रश्न
- चालू घडामोडी वेगळ्या `current-affairs.js` मध्ये: 8 धडे, 139 प्रश्न. प्रत्येक प्रश्नाला कायमचा id (उदा. `ca3-007`), पडताळणी स्थिती व शक्य तिथे स्रोताची लिंक. दर महिन्याला फक्त ही फाइल अद्ययावत करा.
- मॉक टेस्ट (100 प्रश्न, 60 मिनिटे, −0.25)

- एकदा उघडल्यावर इंटरनेटशिवायही चालते (Home screen वर install करा)

प्रगती फोनच्या ब्राउझरमध्ये जतन होते. "प्रगती" पानावरून बॅकअप फाइल घ्या व दुसऱ्या फोनवर तीच फाइल उघडून प्रगती परत मिळवा.
